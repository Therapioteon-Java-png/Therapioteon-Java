# THERAPIOTEON JAVA

Český voxel sandbox ve vývoji, bez povinného přihlašování hráčů.

## Vyzkoušení

Otevři `index.html` v moderním prohlížeči s podporou WebGL. Pokud se moduly nenačtou, použij místní statický webový server. Starší klikací prototyp nabídky je v `prototype/index.html`.

## Aktuální stav

Zdrojový kód hlavního prototypu obsahuje 3D vykreslování bloků, pohyb hráče, kolize, inventář a základní crafting. Funkčnost jednotlivých mechanik zatím není nezávisle ověřena. Nejde o dokončenou hru.

## Plán vývoje

- Rozšíření světa a herních mechanik.
- Testování ukládání, Survival a Creative.
- Skutečný multiplayer a samostatná sestavení pro podporované platformy.
- Digitální podepisování budoucích vydání pro Windows.

Podrobnosti: [GAME_PLAN.md](GAME_PLAN.md). Plánované funkce nejsou příslibem aktuální dostupnosti.

## English summary

THERAPIOTEON JAVA is a Czech voxel sandbox prototype under development. The repository contains a browser-based 3D prototype, an earlier menu prototype and a development plan. Multiplayer and platform-specific builds require further development and verification.
