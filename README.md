# THERAPIOTEON JAVA

Český voxel sandbox projekt bez povinného přihlašování.

## Aktuální obsah repozitáře
- `prototype/index.html` — klikací prototyp hlavní nabídky a nastavení režimů pro jednoho a více hráčů.
- `GAME_PLAN.md` — kompletní sjednocená specifikace funkcí.

## Spuštění prototypu
Otevři `prototype/index.html` v moderním webovém prohlížeči. Není potřeba instalace ani přihlášení. Prototyp zatím simuluje nabídky a volby; neobsahuje 3D svět, ukládání světů ani skutečný multiplayer.

## Stav
Toto je první vývojový základ, nikoli hotová hra. Další práce zahrnuje výběr enginu, 3D svět, ukládání, herní mechaniky a později multiplayerový backend.
